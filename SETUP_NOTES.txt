ProjectPilot — Setup (important information)
=====================================================

What you need
-------------------
• Python 3.11+ and Node.js (npm) must ALREADY be installed and available on your PATH.
• pip and npm need internet access to their registries on first install.

Quick start (two terminals)
---------------------------------
Backend:
  pip install -r requirements.txt
  cd backend
  python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

Frontend:
  cd frontend
  npm install
  npm run dev -- --host 127.0.0.1

On Linux/macOS you can also use: ./run.sh (copies .env.example -> .env if missing and starts both).

After you update the folder (git pull / copy new files)
-------------------------------------------------------
• Run: pip install -r requirements.txt  (stripe/razorpay and other deps may have been added)
• Run: cd frontend && npm install
• Optional: python tools/verify_setup.py
• Start again with the two-terminal flow above.

Network and other failures
----------------------------
• pip and npm need internet access to their registries. If something fails, it is not always an "internet error".
• Disk space, folder permissions, antivirus blocking, corporate proxy, or corrupted caches can all cause failures.
• Read the red error text in the terminal and fix the reported issue (PATH, permissions, etc.).

Security and who is "admin"
----------------------------
• After install, edit .env (copy from .env.example if missing): set JWT_SECRET_KEY and ADMIN_EMAIL / ADMIN_PASSWORD for the first login on THIS machine.
• AI provider keys are NOT in .env — configure them in the UI under Admin -> AI Configuration (encrypted at rest). Test connection there.
• Each deployment / customer environment should use its own secrets and its own Admin -> Users list.
• The product does not lock "system owner" to one person by license; access is controlled by your .env and user accounts you create.

Notes
-------------
• data/app.db is SQLite by default (under data/). Back up data/, uploads/, outputs/ for production.
• No bundled Python/Node installer is included — use official installers and ensure they are on PATH.
• See README.md for full documentation, AI configuration, and troubleshooting.
